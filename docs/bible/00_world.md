## 1. 一句话前提（Logline）

> 《羽锋大乱斗》。赤羽卫和青锋卫在同一块斗场上打。
> 竞猜里你看他们打完，押一边或观望。生存里你守住自己这一边，战斗中可以操控我方一个活着的作战单位。

> ⚠️ **2026-10-21** 取代旧前提：坐在「争锋频道」的观众席上、全程不能下场。旧句留在 `99_decisions.md` 当日条目。

## 2. 世界观设定

| 项 | 内容 |
| --- | --- |
| 舞台 | 《羽锋大乱斗》的斗场。赤羽卫在西，青锋卫在东。场地是被围栏圈起来的方形场地 |
| 玩家身份 | 竞猜是观众。生存是守方。沙盒两边都能摆 |
| 冲突来源 | 竞猜：点数会被打光，观望只有有限次数。生存：没守住就掉血，要守满十个回合 |
| 世界的规则底线 | 选手会死、比赛会结束、点数会归零；但不能读档、不能悔棋 |

### 2.1 世界观的三条硬约束

1. **竞猜里不下场**。⚠️ **2026-10-21**：生存和沙盒的战斗中可以操控一个活着的作战单位，见 `05_ui_hud.md#14`。三个模式都有暂停菜单。
2. **比赛结果必须可归因**：翻盘要能看出是"圈收了/盾挡住了/弓手被贴脸了/轻骑兵冲空了"，不允许纯随机。
3. **模式在开局选定**。竞猜的身份就是观众。生存的身份就是守方。这不是打到一半才揭开的反转。

## 3. 主题（Theme）

- **表层体验**：一场接一场的赌局，刺激、快、有反转。
- **深层主题**：**在信息不完整时下注**——你永远算不清，只能在有限时间里赌一个判断。
- **禁止跑偏**：不做成"操作技巧游戏"，不做成"纯运气的抽卡"，也不做成"策略模拟经营"。
- ⚠️ **2026-10-21**：上面三句是竞猜的调子。生存要自己买人、守住这一边，战斗中可以操控一个单位，见 `05_ui_hud.md#14` 与 `09_roguelike.md`。

### 4.3 白盒阶段的调性落地（当前实现）

- [x] 一个说明空间性质的场景块：方形围栏斗场，明确的东西向对阵
- [x] 一套可交互物的颜色编码：红/蓝队色 + 两队出发区染色
- [x] 尺度参照：1 米 = 1 单位、门框级围栏 3 m；**选手"1.8 m 高" = 本人"头顶 → 地面"的垂直距离，
      与身上的装饰无关**（用户 2026-09-18 明确，口径见下方注）
- [x] 光照基调：单一方向光 + 高环境光，保证任何角度都能看清兵种
- [x] 场地之外的风景层：灰场地是队旗 + 四面的树和岩石，不再放列柱和看台。
      ⚠️ **2026-10-18** 五种战场场景在这圈外面再加树、山、仙人掌、冰川、楼和云，**零碰撞体**（见 `04_physics.md#2.4`）。
      ⚠️ **2026-10-21** 南侧和其余几边用同一套景物。除城市外，场地外的地面有起伏，边线外先留一段平地。没有雪人，没有柳树
- [ ] 待补：转播 UI 的"广播感"包装（看台几何已去掉，界面层仍未做）

> **"1.8 m"的口径（2026-09-18 用户明确）**：它只描述**选手本人**，即**头顶到地面的垂直距离**，
> 与头盔 / 武器 / 队旗这类**挂在人身上的装饰无关**。所以下表的数字都**不**违反它：

| 部位 | 近似高度 | 算不算"1.8 m" |
| --- | --- | --- |
| 选手本人头顶 | **≈1.82 ~ 1.85 m**（各兵种头部半径略有差异） | ✅ 只有这一项算 |
| 头盔 / 兜帽顶 | ≈1.94 m | ❌ 装饰 |
| 长矛尖端（**平直持握**时） | ≈1.05 m | ❌ 武器 |

> ⚠️ **轻骑兵（矛）的"骑马"是怎么装进这套骨架的**（2026-09-25 第四条，用户："修改轻骑兵建模，要骑马"）：
> 人形骨架确实是"躯干 / 头 / 头盔 + 一件武器"三件套、**没有腿**，所以做法是 ——
> **马提供下半身与四条腿，骑手就是"没有腿的上半身"**（人形 / 头盔 / 武器整体挂到 `Rider` 节点上、
> 一起抬高 `MOUNT_RIDER_LIFT` = **0.90 m**）。于是"没有腿"从缺陷变成了正解：**骑手本来就不该有腿露在马腹外**。

>   · **队伍色**落在**鞍垫与两侧护毯**上 —— 骑手躯干被抬高后只占上半身，远看队伍色会变淡，
>     马身必须补一个锚点（色盲测试要求"去掉色相也能分辨"，见 `01_core_loop.md#2`）；
>   · **白斑 + 白袜**是这个模型**唯一**的对比度来源：整匹马都是深棕的话，远看只剩一团黑影，
>     读不出"头在哪、腿有几条"。⚠️ 建模时先做了一版"全深棕"，实机截图确认**确实读不出来**，才补的这两处；
>   · ⚠️ **判定体不跟着马变**（用户 2026-09-25 裁定"判定体不变，只改视觉"）：仍是人形胶囊

> **为什么是"平直"和"弓面在 YZ 平面"，而不是别的朝向**：实战里两队沿 X 对阵，
> 单位是**侧对**相机的（yaw = ±π/2）。本体的 YZ 平面正好摊在屏幕上，X 轴指向屏幕纵深——
> 所以"沿本体 −Z 摊开"的东西（弓面）看得最清楚，"沿本体 −Z 伸展"的东西（平举的矛杆）
> 会横跨整个屏幕。反过来，把弓面朝正前（XY 平面）只有"单位正对相机"时才好看，
> 而实战里永远不会那样站。
